# Popover trigger

Import `PopoverDirective`, `Popover`, `IPopoverConfig` and optional `BX_POPOVER_DEFAULTS` from `@filip.mazev/blocks/primitives`.

The directive owns positioning, focus, dismissal, dialog semantics and theme inheritance; the component supplies the visual surface. Use a native button trigger and a named dialog. See the [popover component guide](../../components/popover/README.md) for working usage, API defaults, configuration, CSS variables and accessibility behavior.

Playground: `/components/popover`.
