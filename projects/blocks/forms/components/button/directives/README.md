# Button icon slot

Import `ButtonIconDirective` from `@filip.mazev/blocks/forms` and mark a custom projected icon element with `bxButtonIcon`. The loading button replaces that element with a same-size spinner and restores it when the operation completes. Built-in `bx-icon` content is recognized automatically.

Provide the action name as button text or an accessible label, and mark decorative custom icons appropriately. See the parent [button guide](../README.md) and `/components/button-loading` playground page.
