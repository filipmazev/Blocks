# Loading button story preview

Generated Angular preview for the Blocks loading button workbench.

## Import

Internal Playground component. Consumers copy the files from the Code panel instead.

## Usage

Edit the owning recipe in `shared/constants/demo-recipes.constants.ts` and run `npm run tools:generate:demo-stories`. Do not edit generated files.

## API

The typed `args` input receives the active story configuration. The `action` output reports component events and model changes to the shared workbench.

## Appearance and customization

The preview uses the public Blocks component, its semantic tokens and the active application appearance.

## Behavior and accessibility

Preview and copied example share the generated Angular template. The library component owns its normal interaction and accessibility behavior.

## Playground

Open `/components/button-loading`. See the colocated library guide at `projects/blocks/forms/components/button/README.md`.
