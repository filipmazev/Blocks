# Page layout playground

Interactive examples for the [Blocks page container](../../../../../../../blocks/primitives/components/page-container/README.md).

## Import

The component catalog loads `PageExamples` through the page-container example.

## Usage

Open `/components/layout/page-container`. Edit the title and description, choose a preview nesting, change the breadcrumb threshold, switch to the current
route, and toggle the footer. The footer button reports its result.

## API

The example uses public `PageContainer`, `PageHeader`, `PageContent`, and `PageFooter` components with Blocks form controls.

## Appearance and customization

The preview follows the current shared theme and appearance configuration. Its nested heading uses level 2.

## Behavior and accessibility

Root and nested preview trails exercise the same threshold as automatic breadcrumbs. The footer action supports keyboard activation and announces its result.

## Playground

Reach this example through **Primitives → Layout → Page container**.
